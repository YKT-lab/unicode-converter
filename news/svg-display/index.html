SVG表示機能を追加しました

一部の端末で文字が正しく表示されない場合に使える、もう一つの表示方法です。

Unicode Converterに、SVG互換モードを追加しました。通常の文字表示がうまくいかない端末でも、サイトが持つフォントの輪郭データを使って文字を図形として描画する機能です。

なぜ追加したの？

Unicodeの番号が正しくても、端末やブラウザのフォント環境によって、文字が四角形や代替記号になったり、サイト側で「未対応」と判定されたりすることがあります。SVG互換モードは、このような表示上の問題を減らすための選択肢です。通常の表示は引き続き基本のモードとして利用できます。

SVG表示とは？

SVG（Scalable Vector Graphics）は、線や曲線などの図形を扱える画像形式です。このサイトのSVG互換モードは、単にSVGの中に文字を置く方式ではありません。フォントの中に記録された文字の輪郭を取り出して、SVGのパス（図形）へ変換します。

  1. Unicode番号を受け取り、ライセンス条件を確認済みの事前生成SVGデータに該当するか調べます。
  2. 事前生成データがある文字は、必要な小さな分割ファイルを取得してSVGの図形として表示します。端末でのフォント解析は不要です。
  3. 事前生成データがない文字や取得できない場合は、端末側で別方式へ切り替えず、「SVG未対応」「SVG通信失敗」「SVGデータ未配信」「SVGデータ不整合」など原因を分けて表示します。
  4. 複数文字のときも1文字ずつ処理します。

事前生成SVGについて

新しい方式では、167,723文字分の輪郭を事前生成しています。Unicode 18.0のSVG輪郭生成可能と確認された167,875文字のうち、約99.9%です。Notoシリーズ、WenJin Mincho、Plangothic、UniHieroglyphica、Kaiyuanの合計97フォントを使い、元データのハッシュとライセンスを公開前に検査しています。対象外の文字も従来のSVG方式で引き続き表示を試みます。

事前生成SVGは端末側のフォント解析へフォールバックせず、公開時に整合性検査されたデータだけを使用します。これにより、PC・iPhone・iPadなどの端末差を減らします。

事前生成データには、各フォントの著作権表示・出典情報・SIL Open Font License 1.1の文書を同梱しています。WenJin Minchoのライセンス文書も公開しています。再配布条件が確認できないフォントの輪郭は、事前生成配信の対象外です。

この方式なら、表示する端末に該当文字のフォントがインストールされていなくても描画できる可能性があります。拡大しても文字の輪郭が滑らかに保たれるのも特徴です。

使い方

トップページの「Unicode → 文字」変換結果の下にある「SVG表示に切り替える」を押してください。切り替えたあとは「現在：SVG表示」と表示され、詳しい説明へのリンクも現れます。文字を入力済みの場合は、そのまま新しい表示方式で描画し直します。入力が空の場合はページを再読み込みして切り替えを反映します。

通常の表示へ戻すときは、同じ場所の「通常表示に戻す」を押します。表示モードはそのタブ内で保持され、新しく開いたタブでは通常表示から始まります。

SVG互換モードの制限

  • SVGモードでは事前生成済みSVGだけを使用します。対象外の文字は「SVG未対応」と表示されます。ランダム生成は最大100文字です。
  • サイト側のフォントにその文字の輪郭がない場合、SVGでも表示できません。
  • 複数の文字を組み合わせる特殊な文字体系や、カラー絵文字などは、元の見た目を完全に再現できない場合があります。
  • SVG互換モードは表示方法だけを切り替える機能です。Unicode番号の規格や文字の意味を変更するものではありません。

通常表示で問題がない場合は、これまでどおり通常モードの利用をおすすめします。どちらの方式も万能ではありませんが、文字を探したり調べたりするときの選択肢が増えました。
