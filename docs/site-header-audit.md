# 共通ヘッダー・ナビゲーション監査（2026-10-27）

調査対象は本番リポジトリ `YKT-lab/unicode-converter` の main、
`022990aaa92cf20b51288036098cf02a4109eb4f`。
変更前のソースを固定して調査・測定・スクリーンショット記録を行い、その後に修正した。

## 重大な問題

確認した範囲で、サイト全体の停止・ナビゲーション先の誤り・入力のHTML実行・Unicodeデータ破損は見つからなかった。
これは全ブラウザ・全Unicode文字についての保証ではない。実機未検証項目は末尾に記載する。

## 軽微な問題（修正済み）

- 開閉・設定ボタンが36〜38pxだったため44pxに統一。520px以下ではロゴに使える横幅が8px減るが、中央配置は維持。
- headerとdrawerの上下左右にsafe-areaを考慮。重複する幅・列・推測高さのモバイルルールを整理。
- reduced-motionの指定が開いたdrawerの詳細度に負けていた。開状態も含めてアニメーションを抑止。
- hiddenなナビ・設定の`inert`、`aria-hidden`、`tabIndex`を同期。開くと内部へフォーカス、Escape/×でトリガーへ戻す。非モーダル方式として、本文へフォーカスが出たら閉じる。
- 設定アイコンは状態が変わったときだけ再生成。ヘッダー高さのCSS変数も同値なら書き換えず、ResizeObserverの不要な再処理を避ける。
- URLチェッカーでMongolian Free Variation SelectorとLRM/RLMの分類漏れを修正。Default Ignorableも検出。入力16px・ボタン44pxへ変更し、位置の数え方と類似文字検出の範囲を説明。

## 問題なしと判断した範囲

### 表示とナビゲーション

375、390、430、519、520、521、619、620、621、768、820、899、900、1024、1280pxで確認。
スマホでは幅260pxの左ドロワー、900px以上では横並びナビを維持する。
修正後のヘッダー実高は、520px以下65px、521〜899pxは73px、900px以上114pxで高さ変数と一致。
通常の844px高では、開いたドロワーは`x=0/y=0/bottom=844`。
高さだけ650pxへ変えた場合も、開いた状態を維持して下端を追従する。

900pxの7項目は約696pxで1行に収まり、左右約102pxの余白がある。
1024px・1280pxもはみ出しなし。900pxブレークポイントやPC側のフォントサイズ・間隔の変更は不要と判断した。

トップ、about、emoji、combining、unicode、url-checker、news、News配下6記事の計13ページを390px/900pxで確認。
共通ヘッダー、本文オフセット、全7リンクのproject prefix、現在ページ表示、横はみ出しを検査する。
PCナビは`aria-hidden=false`・`inert=false`・全リンク`tabIndex=0`であり、スマホとの往復リサイズでも維持する。

### 操作・アクセシビリティ

ドロワーの開閉、×、外側タップ、Escape、キーボードによる退出、設定との相互排他、スクロール位置復元、設定の永続状態を検査。
ヘッダーだけ`user-select:none`等を使用し、本文のコピーは可能。
画像のdraggableを無効化し、設定SVGのpointer-eventsを抑止する既存対策は維持する。
iOSの選択UIが出ないことそのものは実機検証が必要。

### URLチェッカー

`https://m.youtube.com`、`amazon\u200B.com`、BMP/補助平面/MongolianのVS、Greek/Cyrillic類似文字、全Bidi Control、結合文字、不可視文字を検査。
`😀`を含む入力でも`Array.from`によるコードポイント単位の位置は正しい。
入力の勝手な正規化・リンク先へのアクセスは行わず、`textContent`で表示する。
「検出なし＝安全」と断定する表現はない。

### 既存機能・データ・公開処理

既存の変換、ランダム生成関連の入力ポリシー、SVG ON/OFF、Scope、daily情報、結合文字の正規化・候補、色付き絵文字・フォント選択のテストを維持する。
結合文字2,580種類、公式正規化20,171行・456,658assertionを検証。
SVG生成・ライセンス・SHA検証・公開ゲートを実行し、170,775字形／1,594shard／162承認フォントを維持した。
通常/SVGの19文字×390px/1100pxの実ブラウザ比較でもフォント差異は0件。

調査時のmainではPages run `40503422425` とCombining run `40503422631` が成功。
公開サイトの13ページと共通JS/CSSをHTTPSで取得し、調査対象mainと全て一致した。
今回の修正の公開状況はPR/Actions側で別途確認すること。既存mainの公開成功と修正版の公開成功を混同しない。

## テストの実行方法

```sh

node scripts/test-combining-browser.js
```

`test-site-header-browser.js --baseline=<git-ref>`は変更前の比較記録専用で、不具合のないことを判定するモードではない。
`--out=<path>`で保存先を指定できる。ローカルの検証記録は`/workspace/scratch/header-audit/`。
